# 三市成交

A 股、港股、美股的每日成交额，按各自本币归档。新的交易日会补进去，以前的留着。换时间范围看，页面不会越拉越长。

## 页面上有什么

- 三个市场各自的**最新成交额**，以及相对上一交易日的变化
- 时间范围：近十日、近一月、近三月、今年、全部
- 每个市场一张柱状图，下面是按日倒序的成交列表
- 有指数收盘价时，顺手带上指数涨跌

成交额是**成交金额**，不是成交股数。

## 口径

- A 股用人民币，港股用港元，美股用美元，**不换算成同一种货币**
- 三个市场的休市日不一样，日期**不会强行对齐**
- 档案从第一次成功入库的交易日起保留，刷新只会补新的交易日

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认在 `8080` 端口。首次构建会跑数据库迁移，用来保存历史成交：

```bash
npm run build
```

## 声明

行情与成交来自公开市场数据，展示可能有延迟或缺失。仅供信息参考，不构成投资建议。
